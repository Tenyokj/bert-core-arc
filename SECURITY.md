# Security Policy

## Testnet Responsible Disclosure

BERT is actively hardened on Arc Testnet before any mainnet launch. We welcome good-faith reports for the core protocol and BERT V3 Community Layer.

Submit reports privately through [GitHub Private Security Advisories](https://github.com/Tenyokj/bert-core-arc/security/advisories/new). Do not open a public issue for a potentially exploitable vulnerability.

Include the affected contract or module, prerequisites, reproducible steps, expected and actual behavior, impact, and relevant transaction hashes. Do not access other users' funds, expose secrets, degrade service, or use social engineering to demonstrate impact.

For a confirmed, previously unknown high-impact report before mainnet launch, BERT may include the researcher's wallet in `initialValidators` when the official BERT Community is deployed. This is not a cash reward or transferable asset; seats are limited and subject to conduct requirements. After launch, new Validator appointments follow the standard on-chain eligibility path.

See [docs/SECURITY.md](docs/SECURITY.md) for the protocol security model and [the Testnet Guide](https://bertdao.vercel.app/testnet-information) for scope and Arc Testnet Demo verification policy.
